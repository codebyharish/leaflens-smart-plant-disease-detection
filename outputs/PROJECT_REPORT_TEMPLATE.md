## Abstract

LeafLens is a plant-health decision-support system that accepts a photograph of a leaf and predicts its crop–condition class, indicates confidence, screens visible symptom coverage, and presents cautious crop-management guidance. The core model is a ConvNeXt-Tiny neural network transfer-learned from ImageNet and fine-tuned on PlantVillage. The system is exposed through an accessible Streamlit upload interface. Evaluation must distinguish controlled-image performance from real-field generalisation: PlantVillage is used for model development and a held-out PlantDoc/local set is used for field-style testing.

## 1. Problem statement

Manual crop disease identification can be slow and difficult for non-specialists. This project aims to build a practical image-based tool that gives an initial, transparent disease screen while communicating uncertainty and directing the user to safe next actions.

## 2. Objectives

1. Identify the crop and its predicted disease/healthy class from a leaf photograph.
2. Provide a simple web interface usable by non-technical users.
3. Estimate the proportion of visibly discoloured leaf area as a preliminary severity screen.
4. Present disease-aware prevention and management information.
5. Assess the difference between controlled and field-image performance.

## 3. Data

PlantVillage supplies 54,306 colour leaf images across 38 crop–disease/healthy classes and is used for train/validation. PlantDoc and locally collected images are reserved for field-style testing. The datasets are not merged blindly: duplicates are removed, class names are mapped explicitly, and the test set is never used to choose hyperparameters.

## 4. Method

Images are resized to 224 × 224 and normalized with ImageNet statistics. Training augmentation includes random resized crop, horizontal flip, rotation, colour jitter, and random erasing to reduce reliance on PlantVillage’s simple backgrounds. ConvNeXt-Tiny is initialized with ImageNet weights; its final layer is replaced with a 38-class layer. Optimization uses AdamW, cross-entropy with label smoothing, cosine learning-rate decay, and a fixed stratified validation split.

The displayed severity is not trained from disease labels. It is a transparent HSV-based estimate of discoloured area inside a coarse vegetation mask. It is labelled as approximate because shadows, senescence, pests, and nutrient deficiencies can appear similar. A production-grade severity system requires lesion-mask annotations and a segmentation model such as U-Net or DeepLabV3.

## 7. Limitations and ethics

The system is a visual screening aid, not an agronomic diagnosis. It does not identify every species, disease, pest, nutrient deficiency, or regulated threat. Low confidence and out-of-distribution images require expert confirmation. The application avoids product-specific pesticide recommendations; users must follow locally registered product labels and extension guidance.

## 8. Conclusion and future work

LeafLens demonstrates an end-to-end neural disease-classification workflow with an accessible interface and explicit uncertainty. Future work includes balanced field-data collection, an out-of-distribution detector, calibrated confidence, lesion segmentation for validated severity, multilingual guidance, and expert feedback loops.
